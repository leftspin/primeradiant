Current thesis

General memory remembers facts; primeradiant maintains live story state.

Its value is situated awareness: what matters now, what is stale, what changed, what is unresolved, and what is new to this user.

Stack decision: Elixir/Phoenix/Ecto + Postgres/pgvector + Oban. Hiring-market breadth is not a criterion; fit to the living swarm architecture is.

Next move: story-semantics proof

This is not an app build yet. The next implementation step is a deliberately small proof harness that tests whether primeradiant can make concrete story-state decisions.

  • Use a tiny fixed corpus: one public story, one private thread, one user watch, and one stale/no-op case.
  • Normalize each input with provenance, source, timestamp, actors/entities, claims, and links.
  • Classify each input as new story, attach to story, substantive update, repeated/no-op, color/spin, stale, or conflict.
  • Write proposed graph changes with evidence and confidence; do not let agents silently commit truth.
  • Produce one user-facing “what changed for Flynn since last seen, and why” output.

Proof gate: if the harness cannot pass explicit attach/new/update/no-op/color/stale/conflict expectations without demo shortcuts, preseeded trusted state, or broad summarization, primeradiant is not ready for broader implementation.
